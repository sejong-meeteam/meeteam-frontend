# meeTeam 제품 브리프 (리서치 에이전트용)

- **서비스:** 세종대학교 구성원이 프로젝트를 모집하고 팀원을 찾는 웹 서비스(v0.3.2). 메타 설명은 "대학생 전용 팀빌딩 플랫폼", 홈 문구는 "캠퍼스에서 함께할 팀을 쉽게 찾아요".
- **로그인:** 학번(숫자)과 세종대 포털 비밀번호로 합니다. 처음 로그인한 사람만 `/auth/sign-up/sejong`의 "세종대 회원가입" 화면으로 갑니다. 로그인 화면에는 회원가입 링크가 없습니다. 동의 체크박스("비밀번호는 저장하지 않으며…")를 체크해야 "로그인" 버튼이 켜집니다.
- **가입 필수 항목:** 이름, 생년월일, 성별, 분야(직군과 상세 분야), 기술 스택 1개 이상. GitHub, 블로그, 사진은 선택.
- **프로젝트 카테고리:** 캡스톤, 창의학기제, 동아리, 기타.

## 화면과 흐름

| 흐름 | 라우트 | 핵심 |
|---|---|---|
| 탐색 | `/projects` | 검색은 프로젝트 이름이나 리더 이름으로 합니다. 필터는 카테고리, 모집 중만 보기, 플랫폼, 분야이고 정렬은 최신순과 마감순입니다. 무한 스크롤입니다. |
| 상세 | `/projects/[id]` | 탭은 모집 포지션(기본), 소개, 개발 현황, Q&A입니다. 포지션마다 "지원하기" 버튼이 있습니다. |
| 지원 | `/projects/[id]/apply` | "지원 메시지" 하나를 10~1000자로 씁니다(카운터는 "0/1000자"만 보임). 버튼은 "지원서 보내기"이고, 보내면 지원서 상세로 갑니다. "프로필 수정" 버튼을 누르면 `/profile`로 바로 이동합니다. |
| 등록 | `/projects/create` | 4단계입니다: 기본 정보 → 소개 → 모집 역할 → 기술 스택과 마감. 플랫폼은 1개만 고를 수 있지만 칩 모양입니다. |
| 관리 | `/projects/[id]/manage`, `/applicants`, `/edit`, `/github` | 팀원 관리, 지원자 관리(승인/거절/상세), GitHub 연동, 수정 탭이 있습니다. 모집 상태를 토글할 수 있습니다. |
| 팀원 찾기 | `/teammates` → `/profile/[userId]` | 이름 검색, 역할 칩, 기술 스택 필터가 있습니다. 공개 프로필에는 연락하거나 제안하는 버튼이 없습니다. |
| 프로필 | `/profile`, `/profile/applications`, `/settings` | 프로필 수정은 나이를 숫자로 받습니다(가입은 생년월일). |
| 알림 | `/notifications` | "알림 센터", "모두 읽음 처리". |

## 분야 분류 (화면마다 다름)

- 가입: 기획, 디자인, 프론트엔드, 백엔드, 기타 (`constants/interest.ts`)
- 프로젝트 필터: 가입 분류 + 마케팅 (`components/features/project/constants.ts`)
- 팀원 필터: 디자이너, PM/기획, AI, 인프라/운영 등 (`components/features/team/constants.ts`)

## 목업 실행

- `npm run dev:e2e` → `http://127.0.0.1:3005` (MSW 목업, 백엔드 불필요). **지금 이미 실행 중입니다. 다시 띄우거나 끄지 마세요.**
- 데모 계정(비밀번호 `demo1234`): `20260001` 김민지(리더), `20250012` 이준호(리더), `20260002` 신규 가입용, `20260000` 운영자.
- 데이터는 브라우저 localStorage(`meeteam-*`)에 쌓입니다. Playwright에서는 새 context를 쓰면 매번 처음 상태로 시작합니다.
